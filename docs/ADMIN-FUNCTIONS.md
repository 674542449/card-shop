# 管理后台功能清单

适用正式版本：**v1.0.9**，核对日期：2026-11-25。店铺安装见 [首次安装指南](../DEPLOY.md)，架构与校验边界见 [架构说明](ARCHITECTURE.md)。

## 模块概览

| 模块 | 已实现功能 | 处理边界 |
| --- | --- | --- |
| 登录与退出 | 账户密码登录、TOTP / 一次性恢复码验证、退出、会话失效处理 | 登录和写请求校验 CSRF；停用或改密后旧会话立即失效 |
| 经营概览 | 日/月/累计销售、退款和净销售额、七日趋势、最近订单；集中付款待核对、退款待审核 / 待打款、失败通知、低库存待办 | 净销售额不是利润；额外重复收款单独核对 |
| 商品与分类 | 商品分类内联增删改、排序、上下架；商品增删改、富文本、多选批量修改商品介绍、图片、SEO、基础价、阶梯价、起购与限购、低库存阈值 | 有商品的分类禁止删除；有交易关联或保护态卡密的商品禁止删除 |
| 卡密库存 | 粘贴 / TXT / CSV 导入、HMAC 去重、状态筛选、精确搜索、复制、删除未售库存、暂停 / 恢复销售、登记 / 撤销线下售出 | 停用卡不计可售库存且不参与下单/换卡；订单绑定与锁定卡禁止人工改态或回库 |
| 订单列表与详情 | 多维筛选、排序、分页、CSV 导出；关闭未付款订单、人工确认到账、补发邮件、付款同步、回执核对、卡密查看、退款登记、售后换卡及历史 | 人工到账与换卡要求有效管理员会话；服务端统一控制状态转换 |
| 退款管理 | 管理员总开关、申请、批准、拒绝、余额预占、公开说明、内部备注、完成凭证 | **实际打款由操作员在支付渠道完成**，登记完成不会自动转账；关闭开关不阻断既有申请处理 |
| 优惠券 | 固定减额 / 百分比、门槛、商品范围、开始与到期、使用次数、启停、筛选和分页 | 下单重新计价并占用次数；最低实付 0.01 元 |
| 文章与分类 | 文章分类内联增删改；富文本、摘要、封面、嵌入商品卡片、SEO、发布 / 草稿、分类筛选 | 有文章的分类禁止删除；服务端白名单净化内容，发布变更进入 SEO 队列 |
| 任务中心 | 通知投递（邮件 / Telegram 站长告警及商品售出与上架播报）、付款对账任务、搜索引擎推送（百度 / IndexNow）集中查看、筛选与失败重试 | 入队与实际送达/收录分开；对账重试需启用自动对账总开关 |
| 运维中心 | 运行健康（调度、通知、SEO、对账心跳与积压告警）、上传素材（引用检查、满 7 天未引用归档与自动恢复）、完整备份与一键恢复（手动/定时、校验、下载、上传 `.tar.gz` 备份包、从 R2/S3/OSS/COS 列出并拉取还原、本地一键还原） | Web 还原需重验管理员密码并先校验归档与密钥环，由独立 `worker` 进程进入维护模式、创建安全快照并在排他锁下单事务执行；换新机迁移提供 `scripts/restore.sh` 一行命令恢复 |
| 黑名单与日志 | IPv4 / IPv6（含等价写法规范化）/ 邮箱黑名单管理；后台操作日志分页追溯 | 操作日志只读保存 |
| API 令牌 | 新建时一次性显示明文、启停、撤销、有效期、接口范围、IP/CIDR、请求速率及待付款额度 | 数据库仅存 SHA-256 摘要，服务端强制执行范围与配额 |
| 单管理员与账户 | 安装自动生成 24 位随机高强度后台入口（支持 `php artisan admin:path` 查询与轮换）、唯一启用管理员模式、改密、TOTP 双重验证绑定/停用、一次性恢复码 | 数据库部分唯一索引禁止同时启用第二个管理员账户 |
| 系统设置 | 站点信息、三套模板、内联公告、联系方式、SEO、EPay、USDT、SMTP、邮件模板、测试邮件、Telegram（站长告警 + 商品售出/上架多目标播报至私聊/群组话题/频道 + 连通性测试）、Turnstile、下单防刷配额、扫描防护、退款开关、自动备份 | 增量保存已修改字段；敏感密钥使用外部 keyring 加密存储 |

## 卡密状态流转对照

| 实际场景 | 操作 | 结果 |
| --- | --- | --- |
| 怀疑未售卡失效，需要暂时停止销售 | 暂停销售 | `unsold → disabled`，退出可售库存与换卡候选，仍保留导入去重指纹 |
| 已核实停用卡可用 | 恢复销售 | `disabled → unsold`，重新计入可售库存 |
| 已在商城外售出未售卡 | 登记线下售出 | `unsold → sold`，记录售出时间，不生成商城订单或销售额 |
| 误登记线下售出，确认卡密未交付 | 撤销线下售出 | 无订单关联且未换出的 `sold → unsold`，清除售出时间 |
| 订单锁定、已交付或售后换出的卡 | 在对应订单中处理 | 库存页禁止强制回库；停用不代表撤销交易或退款 |

自动化测试覆盖与本地复现命令见 [测试说明](../tests/README.md)。
